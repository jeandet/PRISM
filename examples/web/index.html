PRISM in the browser

The same C++ examples as the desktop build, compiled to WebAssembly with Emscripten — no code changes. Source on GitHub.

Widget Gallery

Every widget in seven tabs, with a catalog of each one: text fields, combo and spin boxes, sliders, radio buttons, color, date and time pickers, icon buttons and tooltips; prose in Hebrew and Arabic mixed with English; a 10,000-row table to sort, edit, tick and rearrange, a tree with boxes and rename, a list that selects; a live plot; dialogs (one holding a form), a popover, a context menu and menus with Alt shortcuts; a dock whose panels the user drags between tab groups.

Notes

A small text editor over PRISM's own sources: selection, copy/cut/paste, undo/redo, input methods, search highlights, a File menu, a rename dialog.

System Monitor

The multi-threaded reference app: sampler threads feed live plots, a sortable process table, a process tree and an event log. In the browser it watches a simulated machine.

Perf Lab

Stress test: a 100k-row table and a 1M-point plot fed by a 1 kHz telemetry thread. The status bar shows what it costs.

Lab Bench & DAQ

Instrument console: DC power supply, waveform generator, live oscilloscope canvas, fault injection, and lossless event log fed by a background hardware simulation thread.

Synth Rack

Press Power and it plays: an arpeggiator, a filter and a delay rendered on an audio thread that never waits for the UI, with a live spectrum and scope. The panel shows the callback's time against its budget.

Data Studio

SQL over 500,000 generated taxi trips. Queries run on a background thread: during a slow one, scroll, edit, switch to the chart, or cancel it.

Task Runner

A build panel: runs stream their output into a console that follows the newest line. The Flood task pours in 200,000 lines while the window keeps up.
Needs a recent browser (Chrome 137+, Firefox 153+, Safari 27): the event loop relies on WebAssembly JSPI. The first visit reloads once to enable threads.
