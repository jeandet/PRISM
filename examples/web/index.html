PRISM in the browser

The same C++ examples as the desktop build, compiled to WebAssembly with Emscripten — no code changes. Source on GitHub.

Widget Gallery

Every widget in five tabs: text fields, combo and spin boxes, sliders, radio buttons, icon buttons and tooltips; prose in Hebrew and Arabic mixed with English; a 10,000-row sortable table, a tree and a list; a live plot; dialogs (one holding a form), a popover, a context menu and menus with Alt shortcuts.

Notes

A small text editor over PRISM's own sources: selection, copy/cut/paste, undo/redo, input methods, search highlights, a File menu, a rename dialog.

System Monitor

The multi-threaded reference app: sampler threads feed live plots, a sortable process table, a process tree and an event log. In the browser it watches a simulated machine.

Perf Lab

Stress test: a 100k-row table and a 1M-point plot fed by a 1 kHz telemetry thread. The status bar shows what it costs.
Needs a recent browser (Chrome 137+, Firefox 153+, Safari 27): the event loop relies on WebAssembly JSPI. The first visit reloads once to enable threads.
